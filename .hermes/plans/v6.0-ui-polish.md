# CyberDiviner UI 优化执行计划

## 目标
4个方向全面加强：导航图标、动画交互、新页面功能、整体视觉风格

## Batch 1: 共享组件 + 视觉基础 (SharedPrefabs)
### 1.1 创建 SharedPrefabs.kt
提取重复的Bridgewater header模式（每个Screen都手写一遍红线下划线）为可复用组件：
- `SectionHeader(title, subtitle)` — 汇文明朝体标题 + Canvas红线下划线 + 英文副标题
- `DividerLine()` — Canvas 1dp 水平分割线
- `StatusLine(text)` — JetBrains Mono 状态行
- `ScanlineOverlay()` — 扫描线叠加效果（全屏半透明横线）

### 1.2 创建 ScreenTransitions.kt
定义NavHost页面切换动画：
- Slide-in from right (进入子页面)
- Slide-in from left (返回)
- Crossfade (Tab切换)

### 1.3 增强 Theme
- 添加背景网格/扫描线效果到 AcidDesign.kt
- 添加 page enter 动画 Modifier 扩展

## Batch 2: 导航图标 + 新页面接入
### 2.1 BottomNavBar Canvas图标
替换 Material Icons 为自绘Canvas图标：
- Oracle: 眼睛符号 (eye)
- Rituals: 三线卦象 (trigram, 复用CyberIcons.IChingIcon)
- Archive: 卷轴/文档符号 (scroll)
- Settings gear → Canvas齿轮

### 2.2 接入 EpiphanyScreen
将 EpiphanyScreen 作为可选的每日入口：
- Splash → Epiphany (tap) → Oracle
- 或从 HomeScreen 进入

### 2.3 接入 ConsultScreen
将 ConsultScreen 接入导航：
- Oracle → Consult (agent访谈模式)

### 2.4 版本号统一
- HomeScreen: "v1.0" → "v6.0"
- TerminalScreen: "v5.0" → "v6.0"

## Batch 3: 页面级增强
### 3.1 HomeScreen 增强
- 菜单项添加 staggered fade-in 动画
- 添加 BinaryClock 到右上角
- CONFIG 按钮改为 Canvas 图标

### 3.2 RitualsMenuScreen 增强
- 每个 CyberMenuItem 添加 Canvas 图标
- Staggered enter 动画

### 3.3 ArchiveScreen 增强
- 卡片展开/收起动画优化
- 添加空状态视图

### 3.4 ConsultScreen 修复
- ASCII dividers ("─".repeat) → Canvas 分割线
- 对齐 Bridgewater 视觉风格

### 3.5 VisionScreen 修复
- ScanAnimation: StrokeCap.Round → Square
- AROverlay: StrokeCap.Round → Square
- 去除遗留的 neon 颜色引用

## 执行策略
3个并行子代理，各自负责一个Batch。完成后统一提交。
